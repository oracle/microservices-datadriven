# Animated technology diagrams

Open [the gallery](index.html) in a browser for a full-screen scrolling sequence, with glowing chapter backgrounds, scroll snapping, and a progress indicator. Each standalone SVG is portable, self-contained, and 800 × 600. Eight-second CSS loops highlight nodes and move signals along connections; all labels and relationships are visible without animation. Reduced-motion preferences disable animation.
